# STM32F407 双轴 GM6020 云台控制

基于 STM32F407 和 HAL 库的双轴云台控制工程。以上板开发板为视角，
Yaw GM6020 使用 CAN1，Pitch GM6020 使用 CAN2；两台电机都设为 ID 2。

## 当前功能

- Yaw、Pitch 双轴 GM6020 控制
- CAN1/Yaw、CAN2/Pitch 独立反馈解析与 `0x1FE` 电流发送
- 单圈编码器多圈累计
- 目标角度劣弧（最短路径）处理
- 位置环、速度环串级PID，以及轨迹/模型前馈框架
- 等待反馈、位置控制、速度调试、故障四状态控制
- 反馈超时后零电流保护
- USB CDC 双轴位置指令输入
- DBUS 遥控器 DMA 接收、摇杆解析与 USART6 监视输出
- DBUS右摇杆分别控制Yaw、Pitch云台位置目标
- DBUS左摇杆控制底盘前进/横移速度，CAN1周期发送控制命令
- CAN1 C610 ID3/M2006拨弹盘速度PID、反馈超时和堵转保护
- CAN2 C620 ID1/ID2双M3508摩擦轮速度环、相反方向和到速诊断
- BMI088初始化、1 kHz六轴采集，以及Pitch二维Kalman融合诊断
- USART6 TX DMA统一输出云台、拨弹盘、摩擦轮、RC、底盘、IMU与融合数据

## 硬件与通信

| 功能 | 配置 |
| --- | --- |
| MCU | STM32F407 |
| CAN1 | PD0 = RX，PD1 = TX，1 Mbps；连接Yaw ID 2、C610 ID 3和底盘通信线路 |
| USART6调试 | PG9 = RX，PG14 = TX，460800-8-N-1；TX使用DMA2 Stream6/Channel 5；对应外壳丝印`UART1`的3-pin口 |
| USB CDC | `yaw,pitch\r\n`，角度单位为度 |
| DBUS | PC11 = USART3_RX，100000-8-E-1，DMA 接收 |
| CAN2 | PB5 = RX，PB6 = TX，1 Mbps；连接Pitch GM6020 ID 2及C620 ID 1/2 |
| BMI088 SPI1 | PB3 = SCK，PB4 = MISO，PA7 = MOSI，5.25 Mbps，Mode 0 |
| BMI088片选 | PA4 = Accel CS，PB0 = Gyro CS |
| Yaw反馈 | 上板CAN1标准帧 `0x206` |
| Pitch反馈 | 上板CAN2标准帧 `0x206` |
| 拨弹盘反馈 | 上板CAN1标准帧 `0x203`，过滤器组1→FIFO1 |
| 摩擦轮反馈 | 上板CAN2标准帧`0x201/0x202`，过滤器组15→FIFO1 |
| GM6020电流命令 | CAN1、CAN2各自发送标准帧`0x1FE`，DLC=8 |
| C610电流命令 | CAN1标准帧`0x200`，ID3使用`DATA[4:5]` |
| C620电流命令 | CAN2标准帧`0x200`，ID1/ID2使用`DATA[0:3]` |

两条总线上的 `0x1FE` 数据分配相同：

| 字节 | 内容 |
| --- | --- |
| `DATA[0:1]` | 填0 |
| `DATA[2:3]` | 本总线 ID 2 电机电流，大端序 |
| `DATA[4:7]` | 填0 |

## 程序流程

```text
USB CDC接收
    ↓
control_in()
    ↓
GM6020_Process()
    ├─ CAN1读取Yaw 0x206，CAN2读取Pitch 0x206
    ├─ 更新多圈编码器
    ├─ 运行状态机
    ├─ 位置环输出目标转速
    ├─ 速度环输出目标电流
    └─ 在对应轴的CAN总线上发送0x1FE电流帧
```

## 双轴串口协议

开发板上电后，Yaw或Pitch收到自己的首帧CAN反馈便独立锁定当前位置，
不会在装机标定前自动转向编码器原始零点。

发送 ASCII 文本 `yaw,pitch\r\n`。Yaw 为相对于标定机械零点的累计
多圈角度，范围为 `-36000~36000` 度；例如 `360` 表示正向1圈，
`1080` 表示正向3圈，`-720` 表示反向2圈。Pitch 仍为单圈位置目标，
范围为 `-31.0~18.5` 度。命令会分别应用到已经在线并完成标定的轴；至少
一轴成功接收时回复`OK\r\n`，两轴都不可用时回复`LOCKED\r\n`，格式
错误时回复`ERR\r\n`。

急停指令为 `ESTOP\r\n`，开发板回复 `ESTOPPED\r\n`。该指令锁存后会
立即将两路 GM6020 电流置零，并通过 CAN1 发送零速度和底盘软件断电
模式；后续位置命令只回复 `LOCKED\r\n`，不会驱动电机。发送
`CLEAR\r\n` 可解除急停，开发板回复 `CLEARED\r\n`。解除后云台锁定
当前位置，底盘仍保持软件断电，不会自动恢复急停前的动作。

## 云台机械零位标定

程序每次上电自动标定，不需要串口触发，也不写入Flash。Yaw逻辑`0°`
直接使用`YAW_SENSOR_ZERO_ECD`配置的GM6020绝对编码器传感器零点，
不再随开机姿态变化；Pitch由BMI088重力角决定，传感器水平为逻辑`0°`。

标定步骤：

1. 上电时保持Yaw和Pitch静止；Pitch可以不在水平位置，但必须位于安全
   机械范围内。
2. 开发板与两台 GM6020 上电。
3. 程序分别等待每个轴数据：Yaw采集100个新编码器反馈；Pitch同步采集
   100个新编码器反馈和100个有效BMI088重力角样本。任一轴不会等待
   另一轴。电机转速超过2 rpm、Pitch陀螺角速度超过静止门限、加速度
   模长不可信或编码器样本跨度超过64时，只重置对应轴样本。
4. 正常约0.1秒可采完；程序从零点生效时继续等待1秒供操作者放手。
   Pitch随后从当前位置开始，以`10°/s`的斜坡目标缓慢回到传感器`0°`。
   目标最多领先实际位置`2°`，到达`±0.5°`且低速保持100 ms后才允许
   遥控器或串口接管Pitch。

如需诊断，可选发送 `CALSTATUS\r\n`：

   - `CALWAIT`：至少一个未标定轴仍在等待有效CAN反馈；
   - `CALMOVING`：云台仍在运动，样本已重置；
   - `CALIBRATING`：正在采样；
   - `CALHOMING`：Pitch正在缓慢回到传感器零点；
   - `CALIBRATED`：零位已经生效且Pitch回零完成；
   - `CALERROR`：零位应用失败、启动姿态越界或回零超时。

编码器采样平均使用跨`8191→0`展开算法，因此编码器零点附近的数据不会
被错误平均到约`4096`。Yaw采样只确认反馈静止，零点始终来自绝对编码器
配置；Pitch零位由重力方向决定，不随开机俯仰姿态变化。如果BMI088安装
面与真实机械水平存在固定偏差，可修改
`Core/Inc/config/pitch_fusion_config.h`中的
`PITCH_SENSOR_LEVEL_OFFSET_DEG`。

回零期间若触发急停或Pitch反馈掉线，斜坡暂停；恢复后先以当前位置重新
建立目标，再继续回零，不会追赶暂停前的旧目标。Pitch实测运行软限位为
`-31.0°~+18.5°`，端点保护始终以编码器位置为准；若已经越界则临时改用
编码器闭环，只允许向限位内恢复。上电回零允许从`-35.0°~+23.0°`包络内
向安全区恢复，但禁止继续向机械端点外侧运动。超过启动包络时进入`CALERROR`且不回零；
8秒内未完成回零时进入`CALERROR`并锁存急停。相关参数集中在
`pitch_fusion_config.h`中。

开发板每 100 ms 主动上报一次：

```text
FB,yaw角度,pitch角度,yaw转速,pitch转速,yaw在线,pitch在线,急停\r\n
```

例如：`FB,732.34,-5.67,100,-20,1,1,0\r\n`。Yaw 上报相对于标定零点
累计的多圈角度；Pitch 上报当前编码器角度。角度单位为度，转速单位为
rpm，在线状态 `1` 表示近期收到对应电机的 CAN 反馈，急停状态 `1`
表示急停已锁存。

## DBUS 遥控器调试输出

开发板通过 USART3 + DMA 接收固定 18 字节 DBUS 帧，主循环解析四个
摇杆通道和两个三挡开关。低优先级`uartDebugTask`格式化数据，通过
USART6 TX DMA以约7.1 Hz输出遥控器和当前底盘待发送命令：

```text
RC_CHASSIS,T=时间,F=总帧,VF=合法帧,IF=非法帧,ON=在线,LV=最近帧合法,
R0=原始CH0,R1=原始CH1,R2=原始CH2,R3=原始CH3,
C0=CH0去中心,C1=CH1去中心,C2=CH2去中心,C3=CH3去中心,
S1=拨杆1,S2=拨杆2,DIAL=拨轮原始值,DC=拨轮去中心值,DV=拨轮有效,
VX=前进速度,VY=横移速度,WZ=旋转速度,
OFF=偏移角,M=底盘模式,CE=底盘急停,TXE=串口发送错误\r\n
```

`VX/VY`放大1000后表示mm/s，`WZ/OFF`放大1000后表示mrad/s和mrad。
原始通道和拨轮正常约`364~1684`、回中约`1024`；去中心值正常约
`-660~+660`。S1/S2编码为上=`1`、下=`2`、中=`3`。如果拨轮上下
功能相反，只修改`control_tuning.h`中的
`TUNE_DBUS_DIAL_DOWN_DIRECTION`。

## BMI088原始数据与Pitch融合诊断

`imuTask` 每1 ms通过SPI读取一次加速度计和陀螺仪，并发布一致的数据
快照。Pitch完成机械零位和500个静止IMU样本标定后，融合器持续计算
角度、角速度和诊断量。当前集中调参配置已经启用受限Pitch融合闭环：
融合正常时使用惯性角和陀螺角速度，失效时自动重新锚定并回退到编码器。
Yaw控制不受影响。当前BMI088配置为：

- 加速度计：`±6 g`、800 Hz、Normal带宽；
- 陀螺仪：`±1000 °/s`、1000 Hz ODR、116 Hz带宽；
- 温度约每秒读取一次，单位为毫摄氏度。

USART6调试任务以约7.1 Hz分别输出原始数据和Pitch融合数据：

```text
IMU_RAW,T=时间,N=样本数,AX=...,AY=...,AZ=...,GX=...,GY=...,GZ=...,TEMP=毫摄氏度,ERR=读取错误,TXE=串口错误\r\n
PITCH_FUSION,T=时间,S=状态,SC=IMU样本,FC=融合次数,CAL=标定样本,AR=原始重力角,AA=对齐重力角,G=陀螺角速度,GB=Kalman零偏,N=加速度模长,E=编码器角度,ER=编码器角速度,F=融合角度,FR=融合角速度,B=安装架扰动角速度,I=创新量,TC=反馈电流,CMD=实际命令,PID=PID输出,FF=前馈,R=恢复样本,H=健康位,RP=恢复等待,TXE=串口错误\r\n
```

其中六轴字段均为有符号16位原始值。换算关系约为：

```text
accel_g = accel_raw / 5460
gyro_dps = gyro_raw / 32.768
temperature_C = temp_mC / 1000
```

静止平放时，三个加速度轴中应有一个轴接近 `±5460`，其余接近0；
三个陀螺仪轴应接近0。`count` 应持续递增，正常时
`error_count` 应保持0。`PITCH_FUSION`中的角度和角速度均放大100倍后
以整数发送，例如`F=1234`表示融合Pitch为`12.34°`。`GB`同样放大100倍；
`TC/CMD/FF`使用GM6020原始电流命令单位，可直接用于重力前馈辨识。

Yaw位置对比通过`POSITION`行约50 Hz输出：

```text
POSITION,T=时间,Y_ACT=Yaw实际位置,Y_REF=Yaw理论位置,
Y_AOK=实际位置有效,Y_ROK=理论位置有效,Y_ASRC=实际位置来源,
Y_RSRC=理论位置来源,Y_MODE=控制模式,TXE=串口错误\r\n
```

位置均放大100倍，例如`Y_ACT=1234`表示`12.34°`。`Y_RSRC=1`表示
位置环内部目标，`Y_RSRC=2`表示纯速度环下由目标RPM积分得到的仅供绘图
理论轨迹；后者不参与电机控制。`Y_MODE=0`表示位置环，`1`表示纯速度环。
默认只发送Yaw；把`Core/Inc/uart_debug.h`中的
`UART_DEBUG_PITCH_POSITION_ENABLE`改为`1U`后，同一行会追加
`P_ACT/P_REF/P_AOK/P_ROK/P_ASRC/P_RSRC/P_MODE`。Pitch实际位置来源
`P_ASRC=1`表示编码器，`2`表示融合反馈。

云台与速度环数据通过`GIMBAL`行约14.3 Hz输出。`YP/PP`为放大100倍的
角度，`YT/PT`和`YER/PER`为放大100倍的目标RPM与速度误差；
`YC/PC`为实际CAN电流命令，`YTC/PTC`为电机反馈电流，
`YM/PM`中`0`表示位置环、`1`表示纯速度环。

融合状态`S`：

| 数值 | 状态 |
| --- | --- |
| `0` | 等待BMI088或Pitch电机数据 |
| `1` | 数据有效，但云台还未静止 |
| `2` | 正在静止标定，`CAL`应增长到500 |
| `3` | 融合正常运行，掉线恢复也已重新通过健康样本检查 |
| `4` | 已标定但数据失效，或正在等待掉线后的安全重捕获 |

`H`的三位依次表示IMU有效、Pitch电机有效、加速度可信；其中加速度必须
同时满足模长门限和创新量门限，正常运行应为`111`。`I`放大100倍，表示
加速度角与陀螺预测角之差；绝对值超过`1200`时，本拍不使用加速度修正。
数据掉线后`R`需连续增长到20，状态才从`4`恢复为`3`。默认假设BMI088
的Y轴为Pitch陀螺轴、X/Z用于重力角计算。
如果实机方向不一致，只修改
`Core/Inc/config/pitch_fusion_config.h`中的轴索引和方向。

Pitch融合使用编码器建立机械零位与IMU安装角偏差，运行中使用二维
Kalman同时估计惯性Pitch角和陀螺零偏：陀螺负责预测，可信重力角负责
观测更新。`B = FR - ER`用于观察底盘或安装架对Pitch轴的扰动。
Kalman的`Q/R/P0`和以下闭环保护参数集中映射到
`Core/Inc/config/control_tuning.h`，当前已经生效：

- 控制用融合角相对编码器角最多偏离`±10°`；
- 融合角速度相对电机反馈最多修正`±180°/s`；
- 融合工作时Pitch目标速度最多`45 rpm`；
- 融合工作时Pitch电流命令最多`±4000`。

首次上电保持云台静止至少1秒，先观察`AR/AA/G/E/ER/F/I/R/H`。缓慢抬头
时`AA、G、E、F`应同号；静止或匀速缓慢运动时`I`不应长期超过门限。
当前固件会直接使用受限融合闭环，因此首次烧录必须架空Pitch并准备急停；
若方向或数据异常，应立即急停并把
`TUNE_PITCH_FUSION_CONTROL_ENABLE`暂时改回`0U`。本阶段暂不启用数据
就绪中断、SPI DMA和IMU恒温加热。

如果初始化配置寄存器失败，会输出首个失败位置：

```text
IMU,CONFIG_ERROR,ACC=0x1E,GYRO=0x0F,CFG=GYRO:0x10,W=0x02,R=0x82,ERR=0
```

`CFG`表示器件和寄存器地址，`W/R`分别表示写入值与回读值。配置未成功
时采集任务不会把每次跳过采样误计入`error_count`。

## DBUS 云台控制

当前`GIMBAL_YAW_ONLY_TEST_MODE=0U`，启用Yaw和Pitch双轴位置控制。
以上板开发板为视角，Yaw通过CAN1、Pitch通过CAN2通信，两台
GM6020均为ID 2。上电分别采集100帧零点后，CH0控制Yaw、CH1控制Pitch：

| 通道 | 动作 | 满杆目标速度 |
| --- | --- | --- |
| `CH0` | Yaw 左右运动 | `180°/s` |
| `CH1` | Pitch 上下运动 | `60°/s` |

两个通道都使用`±30`死区。Yaw回中后保持目标角度；Pitch回中后以
`30°/s`把目标平滑拉回传感器水平`0°`，到达后保持惯性水平。车辆经过
起伏路面时目标不会重新走慢速斜坡，BMI088陀螺角速度以1 kHz直接进入
内环抑制扰动。Yaw目标范围为`±36000°`；Pitch限制在
`-31.0°~+18.5°`。
遥控器掉线或急停会停止两轴更新。除此之外，每轴只检查自己的反馈和
标定状态：Yaw离线不影响Pitch，Pitch离线不影响Yaw；恢复的轴从自己的
编码器当前位置重新接管，避免跳回旧目标。

当前实机方向修正为Yaw `-1.0f`、Pitch `-1.0f`。如果后续更改电机安装
方向，可修改`remote_gimbal_control.c`中的
`REMOTE_GIMBAL_YAW_DIRECTION`或`REMOTE_GIMBAL_PITCH_DIRECTION`。
需要重新进行Yaw单轴测试时，可暂时把
`GIMBAL_YAW_ONLY_TEST_MODE`改回`1U`。

遥控位置轨迹同时提交目标速度前馈，首次装机时Yaw/Pitch增益均为保守的
`0.25`；确认方向和电流响应后再按`0.25 → 0.5 → 1.0`逐步增加。到达
软件限位时按实际目标增量计算，向限位外的速度前馈自动变为0。速度前馈
与角度PID之和统一执行目标转速限幅。速度环还预留以下模型电流前馈：

```text
Iff = A*sin(angle) + B*cos(angle) + C
    + Ks*friction(speed) + Kv*speed + Ka*acceleration
```

重力、摩擦、速度、加速度及Pitch底座扰动前馈系数当前均为0，必须使用
实机日志辨识后在`gimbal_params.h`中逐项启用。PID与前馈的总电流统一
限幅并参与anti-windup；急停、故障、速度调试模式和反馈源切换都会清空
旧前馈。

当前还启用了临时S1安全映射：

| S1挡位 | 动作 |
| --- | --- |
| 上挡 | 锁存云台、底盘、摩擦轮和拨弹盘急停，立即归零 |
| 中挡 | 解除四模块急停；摩擦轮和拨弹盘保持关闭 |
| 下挡 | 解除四模块急停并启动双摩擦轮；底盘保持可控 |

S1上挡具有持续优先权；上挡期间即使USB收到`CLEAR`，也会在下一控制
周期重新急停。中/下挡只在切换进入该挡位时解除一次，不会持续覆盖
USB的`ESTOP`。该映射标记为临时设置，后续可以重新分配S1功能。

S2始终用于选择底盘模式；S1在下挡时，S2同时选择拨弹盘动作：

| S2挡位 | `0x301`模式值 | 底盘模式 |
| --- | --- | --- |
| 上挡 | `1` | 跟随模式 |
| 中挡 | `2` | 不跟随模式 |
| 下挡 | `3` | 小陀螺模式 |

## CAN2双C620/M3508摩擦轮

两台摩擦轮使用CAN2上的C620电调ID 1和ID 2。反馈标准帧为`0x201`和
`0x202`，由过滤器组15以16位列表模式精确路由到FIFO1；Pitch GM6020
`0x206`仍由过滤器组14路由到FIFO0。控制使用标准帧`0x200`：

| C620 ID | 反馈ID | 电流槽位 | 逻辑方向 |
| --- | --- | --- | --- |
| 1 | `0x201` | `DATA[0:1]` | `+1` |
| 2 | `0x202` | `DATA[2:3]` | `-1` |

逻辑正转统一定义为发射方向，ID2在反馈和输出两侧同时取反，因此两个
速度环可使用相同的正目标转速。首次验证参数位于
`Core/Inc/config/dual_m3508_params.h`：

```text
目标转速       100 rpm
目标速度斜坡   200 rpm/s
速度环         Kp=5，Ki=0，Kd=0
电流硬限幅     ±3000 raw（约±3.66 A转矩电流）
电流变化率     50 raw/ms
反馈超时       50 ms
到速条件       两轮误差均≤15 rpm并持续200 ms
过温阈值       80℃
堵转判定       |速度|≤5 rpm且|逻辑命令|≥400持续1000 ms
```

仅`S1下+S2上`请求启动双摩擦轮；退弹模式`S1下+S2中`会关闭摩擦轮。
上电、DBUS掉线重连或急停解除后必须先经过关闭状态，保持运行请求时
单独发送USB `CLEAR`不会自动重新启动。任一
电机反馈超时、过温或堵转都会锁存成对故障并立即发送双零电流。故障
后必须退出发射模式，等待两台电机在线且接近静止100 ms，再重新进入
`S1下+S2上`。

USART6约7.1 Hz输出：

```text
FRICTION,T=时间,INIT=初始化,EN=运行请求,ST=状态,RDY=双机到速,
EST=急停,FLT=故障锁存,FR=故障原因,TGT=目标转速×100,
M1/M2的ON、ANG、RAW原始转速、RPM逻辑转速、E速度误差、
CMD命令电流、ACT反馈电流、TMP温度、AGE反馈年龄,TXE,UTE\r\n
```

## C610/M2006拨弹盘控制

拨弹盘使用CAN1上的C610电调ID 3。反馈标准帧为`0x203`，由过滤器组1
精确路由到FIFO1；Yaw `0x206`仍使用FIFO0，因此两个模块不会互相取走
反馈。控制使用标准帧`0x200`，ID 3电流命令位于`DATA[4:5]`，其余
ID 1/2/4槽位保持0。

拨轮由DBUS第16、17字节的低11位解析，回中约为1024。当前遥控组合：

| S1 | S2 | 拨轮 | 拨弹盘动作 |
| --- | --- | --- | --- |
| 上 | 任意 | 任意 | 急停并立即归零 |
| 中 | 任意 | 任意 | 拨弹盘关闭 |
| 下 | 上 | 中间 | 拨弹盘停止，双摩擦轮运行 |
| 下 | 上 | 向下保持 | 方向A连续拨弹 |
| 下 | 上 | 从中间拨到上方 | 单发一颗；保持上方不会重复触发 |
| 下 | 中 | 向下保持 | 低速方向B退弹，双摩擦轮关闭 |
| 下 | 中/下 | 其他 | 拨弹盘停止 |

上电、遥控掉线、急停、反馈超时、故障和方向切换后都必须重新经过
拨轮中位并保持100 ms。拨弹盘运行时底盘不再强制
`CHASSIS_MODE_SOFTWARE_OFF`，左摇杆仍可控制底盘平移；S2会同时选择
底盘模式和拨弹盘动作。当前拨弹盘不检查摩擦轮`RDY`状态。

M2006减速比为36:1，C610每个转子机械圈反馈8192计数。拨弹盘输出轴
每圈10发，因此单发步距为：

```text
8192 × 36 ÷ 10 = 29491.2 个电机编码器计数
```

代码使用10倍定点累计目标保存`.2`计数余数，不会因每发取整而产生累计
误差。第一次单发从当前位置前进“整发步距+8%弹位”，完成后保存这个
超出相位；以后每次从上一已完成相位严格增加一个弹位，因此相邻目标仍
相差`36°`，8%不会逐发累积。8%只相当于输出轴`2.88°`，远小于下一枚
弹丸的`36°`间距。

接近目标时允许负电流对仍在正转的电机进行制动，但位置外环不会产生
反向目标；超过允许的前向窗口会锁存故障，不反向找中心。到位后进入
独立低电流单向保持，只在弹丸压力把拨盘向后推时提供正向恢复力。拨轮
快速回中仍会完成已经触发的这一发；反馈掉线、急停、故障、连发或退弹
会清除固定相位。PID、动作限流、保持限流、拨轮阈值和超转比例集中在
`Core/Inc/config/control_tuning.h`。

普通停止状态直接输出零电流；单发完成后的HOLD状态只允许低电流正向
保持，不输出反向找位电流。C610错误码非0、软件堵转或单发前向超限会
锁存故障；错误消失并重新保持拨轮中位100 ms后才能解锁。首次使用或
更换C610/M2006后，应先按照电调说明书空载完成电机校准，并确认CAN1上
没有第二个ID 3设备。

USART6约7.1 Hz输出：

```text
FEEDER,T=时间,INIT=初始化,ON=在线,SEQ=反馈帧数,ST=状态,RC=遥控命令,
ARM=已解锁,EST=急停,FLT=故障锁存,FR=故障原因,ANG=角度,RPM=转速,
TGT=目标转速×100,POS=多圈编码器,REF=当前单发相位目标,PE=位置误差,
SHOT=完成单发数,SA=单发运行中,PV=固定相位有效,HOLD=单向保持中,E=速度误差,
P=比例项,I=积分项,D=微分项,
OUT=PID限幅后输出,CMD=斜坡后命令电流,ACT=反馈电流,ERR=C610错误码,
AGE=反馈年龄,TXE=CAN发送错误,UTE=串口发送错误\r\n
```

## 底盘CAN1协议

CAN1与Yaw电机共享物理总线；底盘模块每10 ms发送两帧，不接收Yaw反馈。
标准帧`0x300`的4个字段均为大端序`int16_t` Q10定点数：

| 字节 | 内容 |
| --- | --- |
| `0:1` | `vx × 1024` |
| `2:3` | `vy × 1024` |
| `4:5` | `wz × 1024` |
| `6:7` | `offset_angle_rad × 1024` |

标准帧`0x301`的Byte 0为底盘模式：`0`软件断电、`1`跟随、
`2`不跟随、`3`小陀螺。调用`ChassisCAN_SetCommand()`更新下一周期发送值。

当前遥控映射使用左摇杆：

| 遥控通道 | 动作 | 满杆命令 |
| --- | --- | --- |
| `CH3`纵向 | 底盘前进速度`vx` | `±5.0 m/s`，Q10为`±5120` |
| `CH2`横向 | 底盘横移速度`vy` | `±5.0 m/s`，Q10为`±5120` |

两个通道共用去中心`±30`死区，`wz`和`offset_angle_rad`暂时保持0，底盘
模式由S2选择。遥控掉线、最近帧非法或急停时发送零速度和软件断电模式。
若实机前后或左右方向相反，只修改
`Core/Src/remote_gimbal_control.c`中的对应`DIRECTION`符号。

## 构建

需要 ARM GNU Toolchain、CMake 和 Ninja。

```powershell
cmake --preset Debug
cmake --build --preset Debug --target CAN
```

也可以直接使用 CLion 的 `Debug` 预设构建。

## 使用前配置

1. 在 `Core/Inc/config/gimbal_params.h` 中设置两轴PID和已辨识的前馈参数。
2. 标定 `YAW_ZERO_OFFSET_DEG` 和 `PITCH_ZERO_OFFSET_DEG`。
3. 根据机械结构设置Yaw、Pitch软限位。
4. 检查 `Core/Inc/config/pitch_fusion_config.h`中的BMI088轴向、Pitch
   编码器方向和融合闭环限制。
5. 检查 `Core/Src/main.c` 中的 `SPEED_LOOP_DEBUG_BOOT_ENABLE`：
   - `0U`：正常位置控制；
   - `1U`：上电进入固定转速调试。

当前版本该开关为`0U`，不会上电进入固定转速调试。装机运行前仍需确认
云台活动范围、急停方式、BMI088方向和Pitch融合限制。
