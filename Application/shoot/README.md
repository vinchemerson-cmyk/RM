# 云台双轴与双摩擦轮遥控测试

当前目标为STM32H723VGT6。pitch/yaw 均使用 LQI 位置保持（Manual）。yaw位置增益0.12 A/°、速度反馈增益0.0035 A/(°/s)；pitch仍为0.1、0.01。本次仅将yaw速度反馈从0.003提高到0.0035以测试松杆超调，Q/R、积分范围、±3A限幅和120°/s目标变化率不变。yaw 保留连续旋转和原方向设置，不复制 pitch 的限位。BootSolve 须分别填写每轴模型。UART7 输出 yaw 8通道同步诊断，CAN2双摩擦轮逻辑不变；拨弹与双板通信仍关闭。本次参数尚未上板验证，不代表高频振荡不会复现，须小幅试拨并准备双DOWN急停。

## UART7 yaw FireWater 诊断

可重复 yaw 指令由 `GimbalConfig.hpp` 的 `kYawRemoteCommandTestEnabled` 开启，默认关闭。
左拨杆保持 MIDDLE，右拨杆先离开 UP 再拨到 UP 并保持触发一轮6秒序列：
保持1秒、正向半杆0.5秒、保持2秒、反向半杆0.5秒、保持2秒。
停止触发会取消后续序列并保持当前目标，掉线/双DOWN仍禁用输出。
pitch 输入置零，摩擦轮逻辑不变；保持左拨杆 MIDDLE 避免启轮。
参数对照时保持初始角度、负载与供电一致，详见 Application/README.md。

当前 UART7 已切换为 **8 通道同步控制诊断**，下方旧六通道说明仅供历史 CSV 对照，不再是当前输出格式。
每个控制周期在计算和 CAN 入队尝试后发布快照，串口仍每10ms读取最新快照，不缓存全部1kHz数据。内部继续保留时间、序号、dt、反馈年龄、使能及CAN入队失败计数，但不再打印。

| 通道 | 含义 | 单位 |
|---|---|---|
| CH1 | yaw 连续目标位置 | ° |
| CH2 | 本次计算所用实际连续位置 | ° |
| CH3 | 摇杆给定的位置目标变化率，满杆±120、松杆0 | °/s |
| CH4 | 本次计算所用实际速度 | °/s |
| CH5 | 未限幅位置项电流 | A |
| CH6 | 未限幅速度项电流 | A |
| CH7 | 最终限幅后的逻辑指令电流，禁用为0 | A |
| CH8 | 本次计算所用反馈电流 | A |

CH3仅作诊断，不是独立速度闭环设定值，也不是位置误差折算的等效速度。CH5/CH6 使用实际装载的 K，支持 Manual/BootSolve；当前积分范围为零，正常位置模式限幅前电流为两项之和。固定电流测试下CH3及两项为0，CH7为测试指令。停止时目标变化率、两项与指令均为0。反馈电流并非本条指令的响应，而是计算时收到的最近反馈。
CAN入队失败统计不改变原发送策略。入队成功不代表实际发送或电调执行成功，反馈年龄也不包含电机采样到软件处理前的完整延迟。保持921600、8N1、FireWater；切换后清空旧曲线再采集，避免混合通道。100Hz抽样不能据此精确还原高频振荡。

## 历史六通道格式（用于旧 CSV 对照）

- VOFA+ 串口设为 **921600、8N1**、无流控，数据引擎选 **FireWater**。固件UART7 TX为PE8、RX为PE7；输出只需UART7 TX接USB-TTL RX，并共地，请按实际板卡接口核对接线。
- `ENABLE_ENCODER_UART7=true`，旧回环任务`ENABLE_UART_SERIAL=false`。每10ms输出例如：

```text
30.000,10.000,6.000,0.120,1,0.118
```

- 六个固定通道依次为CH1=yaw目标速度字段（°/s）、CH2=yaw反馈连续角度（°）、CH3=yaw实际速度（°/s）、CH4=yaw指令电流（A）、CH5=反馈年龄（ms）、CH6=yaw反馈转矩电流（A）。当前位置模式不设置速度目标，CH1为0，不能当作摇杆目标变化率或目标角度。电流、角度和速度保留三位小数，年龄为整数。角度不是以正前方为零的单圈角度；CH4是逻辑指令，CH6是反馈电流，均不能证明发送成功。未收到反馈时年龄为-1，过期时保留最近反馈。每10ms采样，不能解析高频振荡。yaw 当前与 pitch 一样保持位置，松杆后仍可能输出保持电流。摩擦轮和遥控保护不变。
- `kEncoderCalibrationOnly=true`注册两轴反馈并无条件发送零电流，保留用户的位置模式/PID配置，不需要编造限位即可编译采集。先支撑云台，双拨杆保持DOWN，手动移动记录中间零位、下限、上限的计数，避免重力下坠或碰撞。
- 当前`kEncoderCalibrationOnly=false`、两轴位置模式开启：pitch水平零位893、代码配置的上顶点120、下顶点1490。位置目标限制在两顶点各内收10°的范围；进入保护区后只允许手动向水平零位退回，松杆或向外拨时Disable；回到安全区才恢复位置保持，不会自动回正。yaw正前方3741，保持累计连续角度目标，重新解锁同步当前位置，不自动回正。
- 开始测试时先支撑云台并放在水平893附近，短时小幅试拨。pitch松杆保持位置目标，重力下仍须注意机构和电流；重新标定可将`kEncoderCalibrationOnly`改回true，先停机再手动移动。

## 接线与用户确认的 ID

| 部件 | 总线 | 电调 ID | 反馈 ID | 指令帧槽位 |
|---|---|---|---|---|
| pitch GM6020 | FDCAN1，PD0 RX / PD1 TX | ID1 | 0x205 | 0x1FE 电流帧 DATA[0:1] |
| yaw GM6020 | FDCAN1，PD0 RX / PD1 TX | ID2 | 0x206 | 0x1FE 电流帧 DATA[2:3] |
| 右摩擦轮 M3508/C620 | FDCAN2，PB5 RX / PB6 TX | ID2 | 0x202 | 0x200 DATA[2:3] |
| 左摩擦轮 M3508/C620 | FDCAN2，PB5 RX / PB6 TX | ID1 | 0x201 | 0x200 DATA[0:1] |

两路均为 Classic CAN、1Mbps。以上引脚是当前固件复用配置，板上 CAN 插座对应关系须按实际板卡确认。CAN2的两轮合并一个0x200帧，DATA[4:7]保持零。标定模式下CAN1两个槽位均为零电流。

GM6020仍用电流控制，不发送0x1FF/0x2FF电压帧。两台电机在RoboMaster Assistant中应开启“电流环开关”（官方说明固件>=1.0.11.2，Assistant>=2.7）。pitch/yaw使用 LQI 直接计算电流，MCU 不再执行两轴 PID，内部电流环由驱动器完成；模型、Q/R 和积分限幅见 `../gimbal/GimbalConfig.hpp`。

协议依据：[GM6020 官方 v1.4 使用说明](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf)，第5至7页。

ID 不同应改 `../gimbal/GimbalConfig.hpp` 的 `kPitchMotorFeedbackId` 和 `ShootConfig.hpp` 的左右轮反馈 ID。两轮 ID 必须唯一。方向默认 pitch/右轮正向、左轮反向，待上板核对；输出与反馈的方向同时变换。

## 操作

1. 移除弹丸、确认机构可安全运动，摇杆居中，双拨杆 DOWN，保持至少三个安全任务周期（任务每 1ms 更新）。
2. 确认 RTT 启动日志显示 LQI ready 后（当前 Manual 不需要模型），左拨杆保持DOWN，右拨杆改UP解除急停。右摇杆上下推动pitch位置目标、左右推动yaw位置目标；两轴松杆保持位置。先小幅试拨，出现震颤或方向异常立即双DOWN，不要依赖松杆停止输出。
3. 左拨杆UP，两轮共同爬升至转子1000RPM（用户当前配置1000RPM/s）；左拨杆MIDDLE或DOWN两轮同时关闭。
4. 右拨杆保持 UP 即可测试；MIDDLE/DOWN 不会驱动拨弹，因为拨弹电机没有注册。
5. 双拨杆 DOWN 急停全部输出。遥控超过 100ms 无合法帧也立即禁止输出，恢复后重新执行解锁。

## 测试模式边界

- 已移除电机反馈超时停机。pitch/yaw位置模式均需首帧定位；之后反馈中断仍可能持续发送电流，位置保护依赖最近反馈，不能代替机械安全措施。
- 双轮保留共同启停、相同目标和爬升，以及“两轮转速都达标才就绪”的联动；未新增转速差交叉补偿。
- 遥控失联、解锁、双DOWN急停、限幅、非法数值/异常周期检查仍保留。pitch位置模式进入端点保护区后临时用速度环单向向内退回；yaw为连续位置保持。
- 移除反馈超时重锚后，反馈中断期间转过半圈以上可能使累计角度失真，不适合直接验证单发位置精度。
- 摩擦轮关闭后发送零电流，不执行受控减速。两轴当前用手填 K；切到 BootSolve 后求解失败不会自动回退到手填 K 或 PID。尚未进行板上整定。
- yaw已启用；恢复拨弹需修改`kEnableFeeder`，旧拨弹ID1已被左轮占用，必须先选择其他拨弹ID，否则编译期校验会拒绝启用。还需重新确认CAN资源、拨盘参数与反馈保护。

## yaw 固定电流隔离测试（默认关闭）

在 `GimbalConfig.hpp` 将 `kYawFixedCurrentTestEnabled` 改为 `true` 后重新编译烧录。
此模式绕过 MCU 位置/速度反馈控制，GM6020 内部电流环继续工作。
保留当前测试幅值 `kYawFixedCurrentTestA=1.3A`（开关关闭，不参与控制），最长 `kYawFixedCurrentTestDurationMs=200ms`。启用前必须将测试幅值降至当前 yaw 限流以内，否则编译检查拒绝。
正常解锁并将右摇杆水平回到20%以内，再向一侧拨动超过20%，输出对应方向的固定电流。
回中、直接换向、急停、遥控失联或超时均撤销电流；持续打杆不会重复触发，需回中后重试。
撤销电流不代表瞬间停转，需留出惯性滑行空间；没有新增电机反馈超时保护。
100Hz同步诊断保持8列，此模式 CH3/CH5/CH6 为0，CH7 为测试电流，CH8 为反馈电流。
固定电流下仍震颤，进一步排查驱动器、供电、机械与反馈；若稳定，优先排查外部速度闭环。
测试后恢复开关为 `false`；pitch、摩擦轮和原调参值不变。本功能不等于已修复振荡。
